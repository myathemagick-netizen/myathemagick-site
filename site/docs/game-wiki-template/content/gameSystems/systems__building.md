# Building


## Masonry, kiln and rot-proof building
<a id="masonry-kiln-and-rot-proof-building"></a>

**Status:** Implemented

Dressed stone, bricks, sealed brick and concrete, treated planks, stairs and slabs; the kiln fires clay to brick and sand to glass.
