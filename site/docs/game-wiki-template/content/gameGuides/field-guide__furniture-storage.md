# Storage

#### <img src="/images/encyclopedia/icons/reference_icons__item_wardrobe.png" alt="item wardrobe" width="32"> <img src="/images/encyclopedia/icons/reference_icons__tier_sprout.png" alt="tier sprout" width="12"> <span style="color:#4f9a2e">**Sprout Wardrobe**</span>



*A tall two-door wardrobe with a carved crown. Clothes still hang in the good ones; set one down and it holds 27 stacks.*

- **Use (X):** search.
- **Storage:** 27 stacks.
- **Get it:** make at workbench (Carpentry 2): 10 Planks + 1 Scrap Metal.
- **Hold X:** pick it up and carry it.
- **Dismantle:** 6× Planks, 1× Spent Scrap Metal.
- **Search (X) finds:** 1–2 Spore Clothes (70%), 1 Sprout Clothes (35%), 1 Mycelial Padded Jacket (10%), 1–3 Spent Cloth Scrap (50%).
- **Taking it apart teaches** Carpentry.
