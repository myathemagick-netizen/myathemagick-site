# Play & Support

**Mycelium: Aftergrowth** is in active development. A Windows development preview exists; it is an alpha for supporters and testers, not a finished game.

## The development preview

- **Platform:** Windows 64-bit. A graphics card with Vulkan support (most from the last ten years) is needed. The most recent build found in the author's builds folder is number 229.
- **How it is delivered:** a zip containing `Mycelium.exe` and a short readme. Unzip and run it. The build number appears in the window title and on the title screen, so feedback can name it.
- **Windows warning:** the build is not code-signed, so Windows may warn about an unknown publisher: choose "More info", then "Run anyway".
- **Saves and settings** are stored in `%APPDATA%\Godot\app_userdata\mycelium`; screenshots (F12) in its `screenshots` folder.
- **Who gets it:** the author has said higher supporter tiers on Ko-fi get alpha and beta builds. **No distribution link has been verified** (see below).

## Distribution links
