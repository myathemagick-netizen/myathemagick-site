# Controls and settings

| Action | Controller | Keyboard / mouse |
|---|---|---|
| Move / look | Left stick / right stick | WASD / mouse |
| Jump | A | Space |
| Sprint | L3 (toggle) | Shift (hold) |
| Break / take apart | RT (hold) | Left mouse (hold) |
| Place / use the held item (eat, drink, fill a bucket or canteen) | LT (hold) | Right mouse |
| Interact: search, pick, sit, open, use a station | X | E |
| Hotbar | LB / RB | Mouse wheel, 1-9 |
| Inventory | Y | Tab / I |
| Character screen (Character, Crafting, Research) | View | C |
| Switch tabs | LB / RB | Q / E |
| Pause and settings | Start | Esc |
| Screenshot | Share | F12 |
| Hide the interface | | F10 (again to bring it back) |

*From the beginner's guide; F10 from devlog entry 125.*

## Settings (Esc, then Settings)

Controls (sensitivity, invert look), Display (field of view, view distance, fullscreen, V-Sync), Interface (compass, hints, interface size), Sound (music, effects and ambience volume) and Graphics (anti-aliasing: Off or FXAA; ambient occlusion; bloom; shadow softness; render scale; heat shimmer; and an "everything off" preset). **If it stutters, lower the view distance first.**
